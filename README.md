# Proyecto DevOps - Sistema de Reserva de Horas Médicas

Aplicación web estática desarrollada para simular un sistema de reserva de horas médicas en una empresa del rubro salud, utilizando contenedores Docker y Nginx.

## Requisitos de Ejecución Local
- Docker Desktop instalado y en ejecución.

## Instrucciones para levantar el servicio
1. Clonar el repositorio o abrir la carpeta en la terminal.
2. Ejecutar el siguiente comando con Docker Compose:
   ```bash
   docker compose up -d --build
